# Updates — 2026-04-24

## Local MQTT Broker Setup (Mosquitto)

### Problem: `ImportError: no module named 'ussl'`
- **Cause:** `mqtt_client.py` always imported `ussl` even for non-TLS connections.
- **Fix:** Made TLS conditional on port — only enabled when `MQTT_PORT == 8883`. Removed the `ussl` import entirely.

### Problem: WiFi connection failed after 10 retries (status 1001)
- **Cause:** `WIFI_SSID` was set to `your-ssid-5g` — ESP32 only supports 2.4GHz.
- **Fix:** Added `wlan.scan()` debug output to identify visible networks. Updated `WIFI_SSID` to `your-ssid` (2.4GHz band).

### Problem: MQTT `ECONNABORTED` (errno 113)
- **Cause:** Mosquitto was not running / not reachable from ESP32.
- **Fix:** Started Mosquitto service, added Windows Firewall inbound rule for TCP port 1883.
  ```powershell
  New-NetFirewallRule -DisplayName "Mosquitto MQTT" -Direction Inbound -Protocol TCP -LocalPort 1883 -Action Allow
  ```

### Problem: Mosquitto only listening on `127.0.0.1:1883`
- **Cause:** `mosquitto.conf` missing `listener 1883 0.0.0.0`.
- **Fix:** Edit `C:\Program Files\mosquitto\mosquitto.conf` and ensure:
  ```
  listener 1883 0.0.0.0
  allow_anonymous true
  ```
  Then restart: `Restart-Service mosquitto`

### Problem: MQTT error code `5`
- **Cause:** Broker refusing connection — `allow_anonymous true` not applied.
- **Status:** In progress.

## Config Changes
